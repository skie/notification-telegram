# CakePHP TelegramNotification Plugin

The **TelegramNotification** plugin allows you to send notifications to Telegram using the Telegram Bot API and the CakePHP Notification plugin. Telegram is a cloud-based instant messaging service with over 700 million active users worldwide.

The plugin provides simple integration with the Telegram Bot API, rich message formatting supporting both Markdown and HTML, inline keyboard buttons for interactive messages, and support for sending photos, documents, and locations. It includes support for multiple bot instances and full integration with CakePHP's Notification system.

The plugin uses the CakePHP HTTP client with no external dependencies, provides full type safety with PHPStan Level 8 compliance, and includes comprehensive test coverage.

## Requirements

* PHP 8.2+
* CakePHP Notification Plugin
* Telegram Bot Token

See [Versions.md](docs/Versions.md) for the supported CakePHP versions.
